## Deployment

### Podman Compose

**1.** Save as `.env` and fill in what is empty:

```env { data-zip-bundle="plausible-podman" data-zip-filename=".env" }
# Plausible Analytics for FreeBSD (Daemonless)
# Copy to .env and edit.

# Where data lives on the host
CONFIG_LOCATION=/containers/plausible
POSTGRES_DATA_LOCATION=/containers/plausible-postgres
CLICKHOUSE_DATA_LOCATION=/containers/plausible-clickhouse

# Public URL Plausible is reached on. Must match what the browser uses:
# the tracking snippet points at it.
BASE_URL=http://localhost:8000

# Database passwords. Change both to random passwords!
# Use only characters A-Za-z0-9 (no special characters or spaces)
POSTGRES_PASSWORD=plausible
CLICKHOUSE_PASSWORD=plausible

# Sign-up after the first account: invite_only (default), true (closed) or false (open)
# DISABLE_REGISTRATION=invite_only

# Timezone (TZ identifier, e.g. Europe/Berlin)
# TZ=UTC
```

**2.** Save as `compose.yaml`:

```yaml { data-zip-bundle="plausible-podman" data-zip-filename="compose.yaml" }
name: plausible

services:
  plausible:
    image: ghcr.io/daemonless/plausible:latest
    container_name: plausible
    restart: unless-stopped
    network_mode: host

    environment:
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-UTC}
      - BASE_URL=${BASE_URL:-http://localhost:8000}
      # Generated into /config/secrets.env on first start if unset.
      - SECRET_KEY_BASE=${SECRET_KEY_BASE:-}
      - TOTP_VAULT_KEY=${TOTP_VAULT_KEY:-}
      # Plausible connects to the postgres and clickhouse below with these.
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD:-plausible}
      - CLICKHOUSE_PASSWORD=${CLICKHOUSE_PASSWORD:-plausible}
      # Databases of your own instead:
      # - DATABASE_URL=postgres://plausible:secret@db.example.com:5432/plausible_db
      # - CLICKHOUSE_DATABASE_URL=http://default:secret@ch.example.com:8123/plausible_events_db
      # Upstream's default: after the first account, new users only by invitation.
      - DISABLE_REGISTRATION=${DISABLE_REGISTRATION:-invite_only}

    depends_on:
      - postgres
      - clickhouse

    volumes:
      - ${CONFIG_LOCATION}:/config

  postgres:
    image: ghcr.io/daemonless/postgres:latest
    container_name: plausible-postgres
    restart: unless-stopped
    network_mode: host
    # Needs SysV IPC
    annotations:
      org.freebsd.jail.allow.sysvipc: "true"

    environment:
      - POSTGRES_USER=plausible
      - POSTGRES_PASSWORD=${POSTGRES_PASSWORD:-plausible}
      - POSTGRES_DB=plausible_db
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-UTC}

    volumes:
      - ${POSTGRES_DATA_LOCATION}:/var/lib/postgresql/data

  clickhouse:
    image: ghcr.io/daemonless/clickhouse:pkg-latest
    container_name: plausible-clickhouse
    restart: unless-stopped
    network_mode: host
    # ClickHouse on FreeBSD needs the long stop: see its image notes.
    stop_grace_period: 60s

    environment:
      - CLICKHOUSE_PASSWORD=${CLICKHOUSE_PASSWORD:-plausible}
      - PUID=1000
      - PGID=1000
      - TZ=${TZ:-UTC}

    volumes:
      - ${CLICKHOUSE_DATA_LOCATION}:/var/db/clickhouse
```

Then run `podman-compose up -d`.

## Requirements
Plausible needs **PostgreSQL** and **ClickHouse**. Both are part of the
compose file; Plausible creates its databases and runs migrations at every
start. Pick `POSTGRES_PASSWORD` and `CLICKHOUSE_PASSWORD` before the first
start: the databases are initialised with them.

## Secrets
`SECRET_KEY_BASE` and `TOTP_VAULT_KEY` are generated into
`/config/secrets.env` on first start, so there is nothing to prepare. Keep
`/config` on persistent storage: a new `SECRET_KEY_BASE` signs everyone out
and a new `TOTP_VAULT_KEY` locks out every 2FA user. To supply your own,
set them in the environment; the environment always wins.

## First run
Open `BASE_URL`: an instance without users goes straight to registration,
and the first account becomes the owner. After that, sign-up is by
invitation only (`DISABLE_REGISTRATION=invite_only`, the default).
`BASE_URL` must be the address browsers use: the tracking snippet points
at it.

## Email
Without an SMTP server Plausible cannot send verification mail; account
verification is off unless `ENABLE_EMAIL_VERIFICATION=true`. See the
[configuration wiki](https://github.com/plausible/community-edition/wiki/configuration)
for every setting.
